**ANSIS Web Theme** is a modern, light SaaS backend theme designed specifically for **Odoo 18.0 Community Edition** with zero proprietary enterprise dependencies.

Originally derived from and incorporating architectural elements of MuK Backend Theme under LGPL-3.0, it elevates the standard Odoo 18 community interface into an enterprise-grade SaaS experience with:

* **100% Full-Width Screen Workspace**: Neutralizes redundant left sidebars (AppsBar) to reclaim 100% viewport width for data tables, form sheets, and chatter feeds.
* **Interactive Brand Chevron Back Navigation (<)**: Displays the active app icon in the top navbar; transforms smoothly on hover from Application → < Application to open the Home Menu overlay without interfering with browser history or Back navigation.
* **Multi-Level Cascading Submenus**: Deeply nested menu hierarchies (e.g. *Settings → Technical → Database Structure → Models*) cascade smoothly into interactive flyout dropdown panels with FontAwesome rightward chevrons (105) and simultaneous hierarchical active state highlighting.
* **Adaptive Navbar Overflow Prevention**: Intelligently measures true available space between brand and systray boundaries, cleanly collapsing excess sections into a responsive + More dropdown without horizontal collisions on smaller screens.
* **Instant Home Menu Overlay with Live Search**: Clean modal overlay with instant keystroke filtering, full arrow key navigation, and HTML5 drag-and-drop tile reordering with hybrid persistence (localStorage + backend ORM).
* **Multi-Company Branding & Wallpaper**: Per-company background wallpapers and auto-generated complementary color palettes (with computed light tints, borders, and hover states).
* **Modern Minimalist Ergonomics**: Underline-style notebook tabs, 1-line minimalist inputs, elevated stat buttons, sticky table headers (thead), frozen selection checkboxes, and sticky aggregates footer (tfoot).
* **Responsive Mobile Offcanvas Drawer**: Native bottom-docked burger drawer with user profile card and 1-tap All Apps access on mobile devices (< 768px).
