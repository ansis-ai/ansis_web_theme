To configure the theme styling and branding:

1. Navigate to **Settings → General Settings**.
2. Scroll to the dedicated **Theme & Branding** section.
3. Configure the following options:
   * **Brand Color Palette**: Select from *Sapphire (Default)*, *Emerald*, *Violet*, *Amber*, *Rose*, *Slate*, or choose *Custom* to input any custom brand hex code (e.g. #ea580c).
   * **Typography Font Family**: Choose between *Inter (Default)*, *Plus Jakarta Sans*, *Roboto*, *Outfit*, or *System Default*.
   * **Layout Density**: Select *Compact* (32px), *Standard* (40px, Default), or *Comfortable* (48px).
   * **Company Wallpaper**: Upload a high-resolution background wallpaper per company.
4. Click **Save**. Assets automatically recompile and propagate across the database.
