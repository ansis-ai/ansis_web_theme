Using the Interactive Navigation Features:

* **Home Menu Overlay**:
  Click on the active app title/icon in the top-left navbar (or hover to see the < back chevron) to toggle the Home Menu. Type directly on your keyboard to instantly filter applications. Press Enter or click to open.
* **Drag-and-Drop App Reordering**:
  In the Home Menu overlay, drag any app card and drop it into your preferred position. Order is persisted instantly both in browser local storage and in the database.
* **Multi-Level Submenus**:
  In desktop view, open any navbar dropdown menu. Submenus with child categories display a rightward chevron (>). Hovering over the item smoothly cascades the nested submenu to the right.
* **Keyboard Navigation in Submenus**:
  Use arrow keys (Up, Down, Right, Left) and Escape to navigate across nested cascading menus without touching the mouse.
