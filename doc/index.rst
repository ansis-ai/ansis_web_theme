===============
ANSIS Web Theme
===============

ANSIS Web Theme is an ergonomic Modern Light SaaS Backend Theme for Odoo 18.0 Community Edition.

Key Capabilities
================
* Interactive brand chevron navigation (<)
* Home Menu app card grid with drag-and-drop reordering
* Instant client-side app filtering
* Sticky list view table headers and frozen selection column
* Underline notebook tabs and elevated stat buttons
* Mobile offcanvas navigation drawer (< 768px)
* Multi-company custom wallpaper support
