===============
ANSIS Web Theme
===============

ANSIS Web Theme is an ergonomic Modern Light SaaS Backend Theme for Odoo 18.0 Community Edition.

Key Capabilities
================
* Dedicated Apps Menu button (9-dot grid) and brand navigation to open Home Menu
* Fullscreen Home Menu app card grid with drag-and-drop reordering
* Instant client-side app filtering with keyboard navigation
* Sticky list view table headers and frozen selection column
* Minimalist 1-line underline input styling
* Underline notebook tabs and elevated stat buttons
* Dedicated "Theme & Branding" application settings
* Dynamic typography font stacks and UI layout density scaling
* Automatic brand palette accent derivation
* Mobile offcanvas navigation drawer (< 768px)
* Multi-company custom wallpaper and favicon support
